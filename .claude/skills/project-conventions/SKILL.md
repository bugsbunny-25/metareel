## Project Architecture

metareel is a Go 1.25 backend service with these layers:

- `internal/handler/` — Echo v5 HTTP handlers. Thin: parse input, call service, return JSON.
- `internal/service/` — Business logic. Orchestrates repository calls and task enqueuing.
- `internal/repository/` — Data access via sqlc-generated code in `internal/repository/sqlc/`. Never write raw SQL outside of `db/queries/`.
- `internal/tasks/` — Asynq background task definitions (payload structs + handler funcs).
- `internal/scheduler/` — Periodic/cron job scheduling using Asynq.
- `internal/scraper/` — Colly-based web scrapers (e.g. flixpatrol).
- `internal/client/` — Typed HTTP clients for external APIs (TMDB, GraphQL).
- `internal/cache/` — Redis-backed caching via go-redis.
- `internal/config/` — Env config loaded with caarlos0/env.
- `internal/router/` — Echo route registration.
- `db/migrations/` — Goose SQL migrations (never edit generated files).
- `db/queries/` — sqlc SQL query definitions.

## Key Conventions

- All DB queries are generated by sqlc — add queries to `db/queries/`, run `make sqlc`.
- Migrations use goose — create with `make migrate-new MIGRATION_NAME=xxx`.
- Config comes from env vars only — extend `internal/config/` for new settings.
- Background jobs use Asynq — define payload in `internal/tasks/`, enqueue from service layer.
- HTTP client is go-resty — configure via `internal/client/`.
- Scraping uses Colly — always set LimitRule and RequestTimeout.
- Dev stack: `make dev-up` starts devredis + asynqmon + air hot-reload.
- Build/test: `make build`, `make test`, `make vet`.
